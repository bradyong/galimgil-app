## Changes

For validated low-confidence AI interpretation only, legacy category fallback,
subject features, forced winners and strong-context keyword bonuses are excluded.
decisionEvidence contains only normalized semantic axes. The existing seeded base
and existing card/zodiac weights score relevant tags. Non-directional axes do not
invent utility weights. The trace records base/card/zodiac and matched tags.
AI receives no winner or score and does not generate either.

The interpretation schema includes grounded scene elements and separate future/
caption variants for both choices in the same single request. Only after code
chooses the result is that choice's variant selected. These scenes never score.
The previous five fixed future/caption templates were removed. Known rule-only
questions use their existing fun content functions.

Validation rejects echoed names, empty contrasts, unsupported directional facts,
invalid axis values, ungrounded quotes, inconsistent activity contrasts, unknown
meanings and invalid scenes. Normalization records discarded axes. No missing
axis is invented to force a pass. No sample-specific vocabulary was added.

## Limits requiring review

Grounded quotations and allowed axes are structural validation, not an entailment
proof. A generally described location or transport mode can still overgeneralize.
When preferences are absent, the score is a playful tie-break, not proof that an
option is objectively better. Reasons explicitly disclose this distinction.
Scene outputs are fictional possibilities, not factual predictions; their quality
still needs user review. Tea now fails safely instead of silently receiving toy
features, but its interpretation still needs improvement before release.
