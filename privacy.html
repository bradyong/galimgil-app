갈림길 개인정보처리방침

시행일: 2026년 10월 14일

개인정보 처리 주체: Galimgil Studio(갈림길 운영자: 이재용).

갈림길은 일상 선택·케미·손금을 즐기는 오락 서비스입니다. 회원가입·로그인·회원 계정을 제공하지 않습니다. 따라서 계정 삭제 절차와 별개로 아래 연락처에서 개인정보 문의와 일반 데이터 삭제 요청을 받습니다.

핵심 안내: 선택지 의미 해석과 미래 댓글, 동의한 손금 분석에는 외부 AI 서비스가 사용됩니다. 최근 기록은 기기에 저장되고, 일부 AI 처리 결과와 이용량은 서버 저장소에 보관됩니다. 삭제 요청은 아래 이메일로 접수하며, 기기 기록·서버 캐시·외부 업체 정보마다 삭제 가능한 범위가 다릅니다.

1. 입력과 AI 처리

고민 문장, 선택 A/B, 마음 온도, 별자리, 결과와 최근 기록은 서비스 제공과 기록 재열기에 사용됩니다. 케미 입력·계산은 기기에서 처리합니다. 앱이 관리하는 최근 기록은 기기의 로컬 저장소에 보관되며 서버 계정으로 동기화하지 않습니다.

선택지의 의미 해석이 필요한 경우 고민 문장과 A/B가 Render의 앱 서버를 거쳐 OpenAI API로 전송됩니다. 의미 확인을 위해 입력한 설명도 앱 서버로 전송될 수 있습니다. 현재 확인 설명은 서버에서 의미를 구성하는 데 사용하며, 기존 FUTURE 요청에는 별도로 전달하지 않습니다.

미래의 나 댓글(FUTURE)은 고민, 원문 A/B, 확정된 선택과 A/B를 나타내는 의미 정보(필요한 경로에서는 차이 정보)를 OpenAI API로 보내 생성합니다. 현재 이 의미·차이 정보는 원문 선택지를 그대로 나타내는 구조입니다. 선택 계산 과정의 마음 온도·별자리·카드 등은 앱 서버로 전송될 수 있지만, 현재 semantic·FUTURE의 OpenAI 입력에는 포함되지 않습니다. 원문 입력에 민감정보나 다른 사람의 개인정보를 적지 않도록 주의해주세요.

2. 손금 이미지와 촬영

사용자가 사진을 선택하거나 촬영하고 동의하여 분석을 요청하면, 사진을 기기에서 크기 조정한 뒤 앱 서버를 거쳐 OpenAI API에 전송합니다. 목적은 손금 놀이 결과 생성이며, 신원 확인·광고·판매를 위한 사진 이용은 하지 않습니다. 앱 서버 코드는 사진을 별도 파일이나 데이터베이스에 저장하지 않습니다. 이는 외부 제공업체에서도 즉시 삭제됨을 뜻하지 않습니다.

Android 직접 촬영 파일은 앱 전용 캐시에 임시 저장됩니다. 촬영 취소·실패 시 정리하고 정상 촬영 파일은 화면을 담당하는 Activity 종료 시 또는 다음 앱 시작 시 정리하도록 구현돼 있습니다. 비정상 종료나 삭제 실패까지 즉시 삭제를 보장하지는 않습니다. 촬영 경로 자체는 갤러리에 별도로 복사하지 않습니다. 앨범 원본과 사용자가 저장한 공유 이미지는 사용자가 직접 관리합니다.

3. 서버 캐시와 이용량 기록

반복 AI 호출과 비용·남용을 줄이기 위해 Upstash Redis에 semantic·FUTURE 처리 결과를 캐시합니다. 키는 요청의 해시이지만 값에는 원문이 반영된 의미·댓글이 포함될 수 있어 완전 익명 정보로 취급하지 않습니다. 검증된 응답(코드상 ready)은 저장 시점부터 7일, 그 밖의 응답과 호출 시도 잠금은 24시간 후 Redis에서 만료됩니다. 캐시 조회만으로 기간을 연장하지 않습니다. 만료 또는 삭제 후 같은 입력이 다시 처리되면 새 캐시가 생성될 수 있습니다. 의미 해석의 불확실성이 높더라도 응답 형식 검증을 통과해 저장된 경우 7일 보관될 수 있습니다.

손금·의미 해석·FUTURE의 이용량은 서로 구분합니다. 서버가 접속 IP를 받아 비밀키 기반 HMAC 식별값으로 바꾼 후 Upstash에 날짜·횟수·전체 합계와 함께 기록합니다. 해당 카운터에는 원본 IP를 저장하지 않습니다. 이는 완전 익명화 보장이 아니라 남용 방지용 가명 처리입니다. 한국 시간 자정 이후 첫 유효 처리에서 전날 상태를 교체하며, 기록 키에는 다음 한국 시간 자정에서 24시간을 더한 만료 시점을 설정합니다. 따라서 횟수 기준 날짜 변경과 저장 정보의 삭제 시점은 같지 않습니다.

위 기간은 앱이 관리하는 Redis 키 기준입니다. Render·Upstash의 접속·보안 로그와 백업 전체에 같은 기간이 적용되거나 즉시 삭제된다고 보장하지 않습니다. 접속 IP는 통신 과정에서 호스팅·저장소 제공업체에 처리될 수 있습니다.

4. 외부 제공업체

Render 앱 서버의 확인된 지역은 미국 오리건입니다. Upstash의 galimgil-palm-usage 데이터베이스는 AWS 미국 오리건(us-west-2)을 Primary 지역으로 사용하는 Free Tier입니다. 2026-10-14 확인 시 일일 백업은 비활성화였고 백업 목록은 비어 있었습니다. 이는 제공업체 내부 복제본이나 보안 로그까지 없다는 의미는 아니며, 그 삭제 시점은 확인되지 않았습니다.

Render는 앱 서버, Upstash는 캐시·사용량 저장소, OpenAI는 의미 해석·미래 댓글·손금 이미지 해석에 사용합니다. 앱에서 OpenAI로 전달하는 요청에는 API 인증을 위한 운영자 키가 사용되며 사용자 Google 계정을 전달하지 않습니다.

OpenAI 계정 화면에서 입력·출력의 모델 개선용 공유, 평가·미세조정 데이터 공유, Playground 피드백 공유는 모두 비활성화로 확인했습니다. API 로깅 설정은 요청별 활성화(Enabled per call)입니다. 모델 개선용 공유 여부와 응답·보안 로그의 보관 여부는 서로 다릅니다.

semantic·FUTURE 요청은 응답 저장 비활성화(store=false)를 지정합니다. 손금 요청에는 이 설정을 지정하지 않습니다. OpenAI 공식 안내상 Responses API 응답 상태는 기본 보관이 적용되며 기본 저장 기간은 30일입니다. 부정 이용 방지 로그는 별도로 기본 최대 30일 보관될 수 있고 법적·보안상 예외가 있을 수 있습니다. store=false는 이 모든 로그의 무보관을 뜻하지 않습니다. 계정별 Zero Data Retention 또는 Modified Abuse Monitoring 적용 여부와 별도 보관 조건은 확인되지 않았습니다. OpenAI 데이터 처리 안내

확인한 OpenAI Default project의 처리 지역 설정은 Global입니다. 특정 국가에서만 처리된다고 단정하지 않습니다. 운영 API 키가 이 프로젝트에 속하는지는 확인되지 않았으므로, 이 프로젝트의 지역 설정을 운영 요청 전체의 확정 처리 지역으로 보장하지 않습니다.

5. 광고와 개인정보 선택

Android 앱은 Google AdMob 배너와 손금 전면광고를 제공합니다. Google Mobile Ads SDK는 광고·측정·분석·부정 이용 방지를 위해 IP 주소(대략적 위치 추정에 사용 가능), 앱/광고 상호작용, 성능 진단, 광고 ID·앱 세트 ID 등 식별자를 처리하고 Google에 전송합니다. 정밀 위치 권한을 요청하지 않으며 고민·A/B·손금 사진·결과 문장을 광고 요청 데이터로 제공하지 않습니다.

필요한 지역에서 UMP 개인정보 선택을 안내하고, SDK가 광고 요청을 허용한 뒤 광고를 요청합니다. 재선택이 요구되는 사용자에게 설정의 개인정보 및 광고 설정 메뉴가 제공됩니다. 동의 거부는 모든 광고나 모든 SDK 처리가 중단됨을 뜻하지 않습니다. 광고 ID는 Android 설정에서 관리할 수 있습니다. 손금 첫 무료 사용 상태·광고 빈도 상태·최근 요청 식별자는 기기에 저장됩니다. Google 개인정보처리방침과 광고 안내가 적용됩니다.
